# 디자인 시스템

테마: Minimal Mistakes (remote_theme), `dark` 스킨.
보정 위치: `_includes/head/custom.html`의 `<style>` 블록. **SCSS를 건드리지 않는다** (이유는 `CLAUDE.md` 참조).

## 조판 규칙 — 측정으로 정한 값

| 항목 | 값 | 근거 |
|---|---|---|
| 한 줄당 글자 수 | **39자** | 한국어 권장 35~45자. 기본값 29자는 너무 좁았다 |
| 본문 폭 | 856px (`#main` max-width 1500px) | 위 값을 만드는 래퍼 폭 |
| H2 / H3 비율 | **1.60 / 1.28배** | 기본값 1.25/1.13은 섹션 구분이 안 보였다 |
| 줄바꿈 | `word-break: keep-all` | 한국어를 어절 단위로 끊는다. 없으면 표 셀에서 "시스템 프롬프 / 트"로 갈라진다 |
| 표 글자 | 본문의 0.88배 | 3열 표가 좁은 셀에 갇히는 문제 완화 |
| 인라인 코드 | `white-space: nowrap` | `/reload-plugins`가 하이픈에서 갈라지는 것 방지 |

**이 값들은 실제 렌더링을 측정해서 정했다.** 바꿀 때도 눈대중이 아니라 측정한다 (`/blog-design` 참조).

## 페이지 구조

```
브레드크럼
제목 (front matter title)          ← 본문 H1 금지
읽기 시간
> 후크 한 문장                      목차 (sticky, 우측)
본문 …
### 참고
```

우측 레일은 목차 자리다. 목차를 끄면 그 공간이 통째로 빈다.

## 이미지 — 3단계 계획

### Level 1: OG 카드 (미착수)

제목 + 블로그명만 있는 텍스트 기반 카드를 자동 생성. 글마다 디자인 작업이 없어야 지속된다.
**전제**: GitHub Actions 빌드 전환 (Phase 2). 현재 플러그인 화이트리스트로는 불가.

### Level 2: 본문 다이어그램 (Mermaid 준비 완료)

마크다운에 ` ```mermaid ` 코드블록을 쓰면 렌더링된다. mermaid 블록이 있는 글에서만 CDN을 로드한다.

**원칙**: 구조·순서·관계를 설명할 때만 쓴다. 표로 충분한 걸 그림으로 만들지 않는다.

미착수 다이어그램:
- prefix 매칭 구조 (2편) — 턴이 쌓이며 앞부분은 캐시에서 읽히는 그림
- 3레이어 구조 (2편) — 시스템 프롬프트 / 프로젝트 컨텍스트 / 대화. 위아래 순서가 의미를 갖는다

### Level 3: 스크린샷 규격 (미정)

정할 것: 다크 테마 고정, 최대 폭, 라운드 코너, 캡션 스타일. 규칙이 있어야 글마다 고민하지 않는다.

## 검증 방법

디자인 변경은 **실제 렌더링을 브라우저로 확인**한다. HTML만 보고 판단하지 않는다.

측정할 것: 본문 폭, 한 줄당 글자 수, H2/H3 비율, `<h1>` 개수, 목차 존재, `word-break` 계산값.
구체적 절차는 `/blog-design` 스킬 참조.
